# Frontend Portfolio — Gabriela Carmona

I am a Frontend Developer focused on building maintainable, user-centered web applications with **React, Next.js, and TypeScript**.

This repository serves as the index for my professional frontend portfolio.

Rather than collecting small tutorial projects, this portfolio focuses on a limited set of applications designed to demonstrate how I approach real frontend engineering problems: requirements, architecture, API integration, state management, validation, testing, accessibility, performance, error handling, and technical trade-offs.

## Portfolio Goals

Across these projects I am intentionally building evidence of:

- React and Next.js application architecture
- TypeScript data modeling
- REST API integration
- Server and client state management
- Forms and validation
- Loading, empty, error, and success states
- Authentication and authorization where appropriate
- Maintainable business logic
- Unit, integration, and E2E testing
- Accessibility
- Responsive design
- Performance optimization
- CI and repository quality
- Technical documentation and trade-off analysis

Each project is developed as a small professional product rather than as a tutorial exercise. Projects are scoped around a clear MVP, released when complete, and may later receive additional iterations as new techniques are learned.
